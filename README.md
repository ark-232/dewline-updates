# Update feed

The signed Sparkle feed history for [Dewline](https://dewline.arkwerx.com), a native Markdown editor for Mac.

| File | What |
|---|---|
| `appcast.xml` | The update feed. Dewline reads it from [dewline.arkwerx.com/appcast.xml](https://dewline.arkwerx.com/appcast.xml). |
| `pulled.txt` | Releases that were pulled. Present only once a release has been pulled. |

The release and pull workflows in [Dewline-ArkWerx-LLC/dewline](https://github.com/Dewline-ArkWerx-LLC/dewline) commit both files. Nothing here is edited by hand.
